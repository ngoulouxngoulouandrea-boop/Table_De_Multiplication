# Table de Multiplication

Ce projet contient deux petits exercices en JavaScript :

- `tables.js` : affiche les tables de multiplication de 1 à 9.
- `fizzbuzz.js` : affiche la suite FizzBuzz de 1 à 100.

## Description

Ce projet a été réalisé pour pratiquer les boucles, les conditions et la logique en JavaScript.

## Prérequis

- Node.js installé sur votre machine.

## Utilisation

1. Ouvrez un terminal dans le dossier du projet.
2. Exécutez la commande suivante pour afficher les tables de multiplication :
   `node tables.js`
3. Exécutez la commande suivante pour afficher la suite FizzBuzz :
   `node fizzbuzz.js`
